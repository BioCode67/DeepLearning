1장인공지능·머신러닝·딥러닝의 이해

  • 인공지능: 인간의 학습능력·추론능력·지각능력을 인공적으로 구현하려는 기술. 용어는 1950년대에 생김.
  • 포함 관계: 인공지능 ⊃ 머신러닝 ⊃ 딥러닝.
  • 머신러닝: 명시적 프로그래밍 없이 데이터로 학습해 작업 성능을 높이는 기술. 알고리즘을 모델이라고도 부름.
  • 톰 미첼의 정의: 작업 T(task), 성능 척도 P(performance), 경험 E(experience). E를 통해 T에 대한 P가 개선되면 학습한 것.
  • 명시적 프로그래밍: 입력 + 규칙 → 출력 (예: 키 160cm 이상 놀이기구). 머신러닝: 입력 + 출력 데이터 → 규칙을 학습.
  • 튜링 테스트(앨런 튜링): 평가자가 기계와 인간을 구분 못 하면 통과. 통과=지능인지는 논쟁거리.
  • 뇌: 신경세포 약 1,000억 개, 연결 약 100조 개. 수상돌기(입력) → 세포체(합이 임계값보다 크면) → 축삭 말단(전달).
  • 인공 신경세포 = 퍼셉트론. 입력 × 가중치(=파라미터)의 합.

2장딥러닝을 위한 기초 지식

  • 함수: 각 입력에 출력이 정확히 하나 (디리클레). 일차 함수 y=ax+b는 선형 함수, a=기울기, b=y절편.
  • 이차 함수 y=ax²: a>0 아래로 볼록, a<0 위로 볼록, |a|가 클수록 폭이 좁음. y=a(x−p)²+q는 x축 방향 p, y축 방향 q만큼 평행이동.
  • 미분 = 순간 변화율 = 접선의 기울기: f'(a)=limΔx→0 [f(a+Δx)−f(a)]/Δx. 공식: (xⁿ)'=nxⁿ⁻¹, (c)'=0, (ex)'=ex.
  • 연쇄 법칙(합성함수 y=f(g(x))): t=g(x)로 두면 dy/dx = dy/dt · dt/dx. 오차 역전파의 핵심.
  • 목적 함수 = 손실 함수(loss) = 비용 함수(cost). 이를 최소로 만드는 x*를 찾는 것이 최적화.
  • 경사하강법: 기울기의 반대 방향(−f'(x))으로 이동. 기울기 >0이면 왼쪽(−), <0이면 오른쪽(+)으로.
  • 편미분: 한 변수로만 미분, 나머지는 상수 취급. f=x²+xy+y² → ∂f/∂x=2x+y, ∂f/∂y=x+2y. 기울기 벡터의 반대 방향에 최적해가 있고, η(학습률)을 곱해 이동.

  • 회귀: 예측값이 숫자(키→몸무게). 분류: 예측값이 범주형(스팸/정상), 목표값=클래스. 이진 분류 / 다중 분류.

4장선형 회귀와 경사하강법

  • 특성(feature): 측정 가능한 개별 속성, 학습 결과에 영향을 주는 입력.
  • '회귀' 용어: 프랜시스 골턴. 회귀 분석 = 대표적 지도학습, 독립변수(원인, 예: 주택 면적)와 종속변수(결과, 예: 거래 가격)의 관계 추정.
  • 모델/가설: y = ωx + b. x는 바꿀 수 없고, 조절하는 것은 기울기 ω와 절편 b.
  • 회귀에서 T=종속변수 추정, E=주어진 데이터, P=예측값 ŷ과 y의 차이가 작을수록 높은 점수.
평균 절대값 오차 MAE
MAE = (1/N) Σ |yᵢ − ŷᵢ|
평균 제곱 오차 MSE
MSE = (1/N) Σ (yᵢ − ŷᵢ)²
  • MSE를 쓰는 이유: 오차가 크면 값이 급격히 커져 나쁜 모델을 강하게 알림, 항상 양수, 볼록한 그릇 모양 곡면 → 기울기를 따라 내려가 최소값 도달 가능. 회귀에서 널리 사용.
  • MSE가 최소인 직선을 찾는 과정 = 최적화 = 머신러닝의 학습 과정.
  • 예: 데이터 (1,2),(2,4),(3,6) → 최적 기울기 m=2 (MSE=0).

정규화 vs 표준화

정규화 (MinMaxScaler) → 0~1
x' = (x − xmin) / (xmax − xmin)
표준화 (StandardScaler) → 평균 0, 표준편차 1
x' = (x − μ) / σ

이유: 특성 스케일이 다르면(건축 연도 3~56년 vs 방 1~4개) 큰 스케일 특성이 예측을 좌우함.

5장신경세포와 퍼셉트론

  • 신경세포: 세포핵, 수상돌기, 축삭, 축삭 말단. 나트륨·칼륨으로 화학 신호.
  • 연결주의: 신경세포 구조를 흉내 내 지능 구현 (로젠블랫, 1958). 당시 주류는 기호주의, 비판의 선봉은 마빈 민스키.
  • 신호 합산 σ = Σωᵢxᵢ → 활성화 함수 φ(σ) → 출력. 노드(node)=입력값을 가진 원.
  • 활성화 함수의 주요 목적: 비선형성 도입. 선형만 쓰면 층을 쌓아도 의미 없음. 종류: 시그모이드, ReLU, tanh, Leaky ReLU.
  • 계단 함수: 임계값(문턱값, threshold) 이상이면 1, 아니면 0.

XOR단층 불가 → AND(OR, NAND)0110
  • 편향(bias): Σωx ≥ 0.8 을 Σωx − 0.8 ≥ 0 으로 바꾼 −0.8. 입력이 항상 1인 노드의 가중치로 해석. 활성화 함수는 "0 이상이면 1"로 단순해짐. 코드: x = np.array([t[0], t[1], 1]).
  • 결정 경계: AND는 .5x₁+.5x₂−.8 ≥ 0 → x₂ ≥ −x₁ + 8/5 (기울기 −1, 절편 1.6 위쪽). OR은 x₂ ≥ −x₁ + 3/5.
  • XOR(배타적 논리합): 입력이 다를 때만 1. 직선 하나로 분리 불가 → 민스키 1969 → 1차 AI 겨울.
  • 해결: 은닉층(hidden layer)을 가진 다층 퍼셉트론. 문제는 가중치를 어떻게 학습시키나 → 오차 역전파.
  • 층이 늘수록 자유도 증가, 비선형 활성화로 곡선 경계, 고차원에서는 초평면(hyperplane).
  • 헵의 학습 법칙(도널드 헵): "함께 활성화되는 세포는 함께 연결된다". 퍼셉트론 학습은 여기에 근거하되 목표치를 주고 가중치를 맞춰간다는 점이 다름.
퍼셉트론 학습식 (오차 E = t − ŷ)
ωk+1 = ωk + η (tk − ŷk) xk
  • 많은 퍼셉트론을 한꺼번에 계산 → 행렬 + 병렬 처리(엔비디아 GPU).

6장오차 역전파

  • 학습 단계: ① 순전파(입력×가중치 → 출력) ② 오차 = 목표 t − 출력 ŷ ③ 역전파(오차의 미분을 거꾸로 전달해 가중치 조정). 반복.
  • ∂E/∂ω: ω에 대한 E의 편미분. ω ← ω − η·∂E/∂ω.
  • 계산 그래프: 계산을 노드(연산)와 간선(이동)으로 표현. 중간 노드의 미분값 = 국소적 미분값 = 지역 기울기. 순전파 때 미리 구해 두고 역전파 때 연쇄법칙으로 곱함.
  • 역전파 출발점: ∂f/∂f = 1.
노드역전파 규칙
덧셈 q = p₀ + p₁지역 기울기 1 → 위에서 온 값을 그대로 양쪽에 전달
곱셈 f = a·b위에서 온 값 × 상대편 입력값 (서로 바꿔 곱함)
시그모이드위에서 온 값 × σ(x)(1−σ(x))

예제 1: f = (x + y)·z, x=100, y=200, z=0.5

q = x+y = 300, f = qz = 150. ∂f/∂z = q = 300, ∂f/∂q = z = 0.5 → ∂f/∂x = ∂f/∂y = 0.5.

예제 2: 동윤이 장보기 (바나나 3개×1,000원, 음료 2개×2,000원, 세금 1.1)

f = (ω₀x₀ + ω₁x₁)·ω₂, ω₀=1000, x₀=3, ω₁=2000, x₁=2, ω₂=1.1 → p₀=3000, p₁=4000, q=7000, f = 7,700

시그모이드

함수와 미분
σ(x) = 1 / (1 + e−x) σ'(x) = σ(x)(1 − σ(x))
  • 계단 함수는 미분 불가 지점이 있고 나머지는 미분값 0 → 역전파 불가 → 모든 구간 미분 가능한 시그모이드 도입.
  • σ(0)=0.5, σ'(0)=0.25 (최대값). 미분값이 0~0.25로 작아 층을 지날수록 0에 수렴 → 기울기 소실. 계산 비용도 큼.
  • 계산 그래프 (입력 1.0): ×(−1) → −1.0 → exp → 0.37 → +1 → 1.37 → 1/x → 0.73.
  • 역전파: 1 → 1/x 노드 (−1/x²) = −1/1.37² ≈ −0.53 → +1 노드 그대로 −0.53 → exp 노드 ×e−1(0.37) ≈ −0.2 → ×(−1) 노드 → 0.2. 확인: σ(1)(1−σ(1)) = 0.73×0.27 ≈ 0.2.

ReLU

  • ReLU = 정류 선형 함수: f(x) = max(0, x). 미분: x>0이면 1, x<0이면 0.
  • 장점: 양수에서 기울기 1 → 기울기 소실 가능성 낮음, 계산 간단, 깊은 신경망에서 시그모이드보다 좋음.
  • 단점: 음수 입력은 출력·기울기 모두 0 → 죽은 ReLU. 대안: Leaky ReLU, PReLU, ELU.
  • 역전파 역사: 아이디어 1950년대 말 → 정체 → 2006년 이후 부각.

7장텐서플로로 구현하는 딥러닝

  • 텐서플로: 구글, 설계·훈련·배포. CPU/GPU(그래픽 처리 장치)/TPU(텐서 처리 장치, 구글) 지원.
  • 케라스: 고수준 API (텐서플로, 테아노, CNTK 위에서 실행).
  • MNIST: Modified National Institute of Standards and Technology. 손글씨 0~9, 28×28 회색조, 픽셀 0(어두움)~255(밝음). 숫자당 6,000장 → 훈련 60,000, 테스트 10,000.
mnist = keras.datasets.mnist
(train_images, train_labels), (test_images, test_labels) = mnist.load_data()
train_images.shape   # (60000, 28, 28)
train_labels.shape   # (60000,)
test_images.shape    # (10000, 28, 28)
train_labels[:4]     # [5 0 4 1]
plt.imshow(train_images[0], cmap='Greys')   # 숫자 5

모델 만들기 6단계

# 1단계: 전처리 (정규화) 0~255 → 0~1
train_images, test_images = train_images / 255, test_images / 255

# 2단계: 모델
model = keras.models.Sequential([
    keras.layers.Flatten(input_shape=(28, 28)),       # 784개 1차원
    keras.layers.Dense(60, activation='relu'),        # 은닉층 60
    keras.layers.Dense(10, activation='softmax'),     # 출력 10
])
model.summary()      # 파라미터 47,710

# 3단계: 최적화 함수, 손실 함수, 측정 방법
model.compile(optimizer='adam',
              loss='sparse_categorical_crossentropy',
              metrics=['accuracy'])

# 4단계: 학습
model.fit(train_images, train_labels, epochs=3)

# 5단계: 정확도 (처음 보는 데이터)
test_loss, test_acc = model.evaluate(test_images, test_labels, verbose=2)

# 6단계: 성능 개선 (층·노드 늘리기, 데이터 늘리기, 에폭 늘리기, 부분 연결망 등)
파라미터 수 (가중치 + 편향)
(784 × 60 + 60) + (60 × 10 + 10) = 47,100 + 610 = 47,710
  • Flatten: 2차원 이미지를 1차원으로 (기하학적 정보 손실 → 나중에 CNN). 28×28 = 784.
  • Dense = 완전 연결층(fully connected). 4노드-4노드면 연결 16개. 784×60 = 47,040 연결, 은닉층은 편향 포함 61개 노드처럼 봄.
  • accuracy = 맞힌 수 / 전체. 60,000개 중 54,000개 → 0.9.
  • 배치: 데이터를 나눈 학습 단위. 기본 32 → 60,000/32 = 1,875번 반복 = 1 에폭. Epoch 4/5 = 5회 중 4회째.
  • 훈련이 진행되면 loss ↓, accuracy ↑. 테스트 정확도는 보통 조금 낮음 (예: 0.7907). 초기 가중치가 랜덤이라 매번 결과가 다름.
  • verbose: 0 = 침묵, 1 = 진행 막대, 2 = 에폭당 한 줄.
  • 참고: sparse_categorical_crossentropy는 정수 레이블(5, 0, 4…)을 그대로 쓰고, categorical_crossentropy는 원-핫 레이블을 씀.

소프트맥스

정의 (출력 합 = 1, 0~1 확률)
yk = eak / Σi eai

a = [0.5, 4.1, 2.5, 5.6, 1.2] → 분모 Σea ≈ 347.9 → [0.0047, 0.1734, 0.0350, 0.7772, 0.0095], np.argmax = 3 (77.72%).

  • '부드러운' 최대값: max/argmax는 하나만 반환하지만 소프트맥스는 다른 값의 확률도 유지.
  • 입력을 2배로 하면 최대값 확률이 더 커짐 (0.9506) → 큰 값은 강화, 작은 값은 억제 (지수함수라서).
  • np.set_printoptions(precision=4, suppress=True): 정밀도 / 지수 표기 억제.

원-핫 인코딩

  • 레이블 0,1,2,3,4의 순서적(서수) 관계를 없애기 위해 이진 벡터로: 3 → [0, 0, 0, 1, 0].
  • keras.utils.to_categorical([0,1,2,3,4]). 문자열('red','green','blue')은 딕셔너리로 번호를 매긴 뒤 변환.
  • 정답 3(원-핫) vs 소프트맥스 출력의 MSE = 0.0162. 예측 [0.1, 0.3, 0.5, 0.02, 0.08]이면 MSE = 0.26336.

교차 엔트로피 오차 (CEE)

정답 t는 원-핫이어야 함, log = 자연로그
ECEE = − Σk tk log ŷk → 정답 위치의 −log ŷ 만 남음
  • 정답 위치 예측 0.77 → −log 0.77 ≈ 0.26. 0.035 → −log 0.035 ≈ 3.35.
  • 정답 [0,0,1], ŷ₁=[0.4, 0.05, 0.55], ŷ₂=[0.9, 0.09, 0.01] → CEE 0.60 vs 4.61 (7.7배), MSE 0.12 vs 0.61 (4.93배). CEE가 틀린 예측에 벌점을 더 크게 → 학습이 빠름. 레이블이 많아도 정답 항만 계산 → 계산량 적음.

옵티마이저

  • 손실 함수를 최소화하는 매개변수를 찾는 방법. 경사하강법 계열: SGD(확률적 경사하강법), 모멘텀, RMSProp, Adam(가장 흔히 씀, 모멘텀+RMSProp 아이디어).
  • 지역 최적점(local minimum): 주변에서는 가장 낮지만 전체 최소는 아닌 곳. 갇히면 최고 성능에 못 감.
  • 지정 방법: optimizer='adam' 문자열 또는 keras.optimizers.Adam(learning_rate=0.001) 객체.

지도: 레이블(정답)이 있는 데이터로 입력→출력 규칙 학습. 비지도: 레이블 없이 숨은 구조 발견 (군집화). 강화: 에이전트가 환경에서 행동하고 보상을 최대화하도록 정책을 바꿈 (알파고). 회귀: 숫자 예측 (키→몸무게). 분류: 범주 예측 (스팸/정상 메일).
